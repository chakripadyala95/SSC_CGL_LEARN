# Analogy: cheat sheet

- [Word-pair relationship](/formulas/analogy#word-relation): $\text{Name the exact relation in } A:B \text{ (synonym, antonym, worker-tool, country-river, item-category), then pick the option } C:D \text{ with the same relation in the same order.}$
- [Number pair arithmetic rule](/formulas/analogy#number-arithmetic-rule): $a \mapsto b:\ \text{try } b = ka + c \ \text{(includes } a+c \text{ and } ka\text{)}, \text{ fit } k, c \text{ from the two given pairs and test every option}$
  - Shortcut: Check $b - a$ first (constant difference = add rule), then $b \div a$ (constant ratio = multiply rule).
- [Square/cube based number rule](/formulas/analogy#number-power-rule): $a \mapsto b:\ \text{test } b = a^2 + c \text{ or } b = a^3 + c \text{ (and the reverse, } a = b^2 + c\text{) before linear rules}$
- [Number triad operation rule](/formulas/analogy#number-set-rule): $(x, y, z):\ \text{find the one operation that turns two terms into the third (} xy + k,\ (x+y)k,\ xyk \text{, or } z = 2y+1 \text{ chains) on every given triad; whole numbers only}$
- [Letter-cluster position shift](/formulas/analogy#letter-cluster-shift): $d_i = p(\text{code}_i) - p(\text{word}_i) \pmod{26};\ \text{the } d_i \text{ are constant, alternating or increasing; apply the same } d_i \text{ to the target}$
  - Shortcut: A shift of $\pm 13$ is the same both ways: A$\leftrightarrow$N, B$\leftrightarrow$O, ... .
