# Average: cheat sheet

- [Arithmetic mean](/formulas/average#arithmetic-mean): $\bar x=\frac{\Sigma x_i}{n};\ \text{sum}=n\times\bar x$
  - Shortcut: Assumed mean: $\bar x = A + \frac{\Sigma(x_i - A)}{n}$ (e.g. 94.5 = 93 + 9/6 for marks 98, 97, 93, 94, 92, 93).
- [Weighted / combined average](/formulas/average#weighted-average): $\bar x=\frac{n_1\bar x_1+n_2\bar x_2}{n_1+n_2}$
  - Shortcut: Start at $\bar x_1$ and move toward $\bar x_2$ by the second group's share: $\bar x = \bar x_1 + (\bar x_2 - \bar x_1)\frac{n_2}{n_1+n_2}$.
- [Replacement of a member](/formulas/average#replacement): $\text{new}-\text{old}=n\times(\text{change in average})$
- [Average of an AP / consecutive numbers](/formulas/average#ap-mean-middle-term): $\text{mean of an AP}=\frac{\text{first}+\text{last}}{2}=\text{middle term};\ \text{mean of } 1..n=\frac{n+1}{2}$
  - Shortcut: Consecutive numbers with sum $S$ and count $n$: middle $= \frac Sn$; step out by the gap to reach the ends.
