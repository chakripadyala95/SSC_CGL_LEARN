# Blood Relations: cheat sheet

- [Decode symbol relations](/formulas/blood-relations#symbol-decoding): $\text{Decode each symbol into a relation, draw it on a family tree with gender marks, and read the relation between the two end persons.}$
- [Family tree diagram](/formulas/blood-relations#family-tree): $\text{Draw generations as rows, mark + (male) / - (female), join couples with =, then trace the path between the two persons.}$
- [Pointing/introduction statements](/formulas/blood-relations#pointing-statements): $\text{Resolve the sentence from its end towards the speaker ('my father's only son' = the speaker if male), then name the pointed person's relation.}$
