# Puzzles/Seating: cheat sheet

- [Linear seating arrangement](/formulas/seating#linear-arrangement): $\text{Fix the most definite clue first, draw the seats, place the rest clue by clue, and flip left/right for people facing south.}$
- [Circular seating arrangement](/formulas/seating#circular-arrangement): $\text{Fix one person, then place the rest relative to fixed seats; facing the centre, right = anticlockwise, facing outward it flips.}$
