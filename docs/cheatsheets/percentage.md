# Percentage: cheat sheet

- [Percent of a quantity](/formulas/percentage#percent-of-quantity): $x\%\text{ of } N=\frac{x}{100}N;\ x\%\text{ of } y\%\text{ of } N=\frac{xy}{10^4}N;\ \text{share}\%=\frac{\text{part}}{\text{whole}}\times100$
  - Shortcut: $x\%$ of $N$ = $N\%$ of $x$ (e.g. $16\%$ of $25$ = $25\%$ of $16 = 4$); $10\%$ = shift the decimal one place.
- [Percentage change](/formulas/percentage#percent-change): $\%\text{ change}=\frac{\text{new}-\text{old}}{\text{old}}\times100$
  - Shortcut: Use the multiplier: % change $= (\frac{\text{new}}{\text{old}}-1)\times100$; a sign tells rise or fall.
- [A is r% more than B, so B is ?% less than A](/formulas/percentage#more-than-less-than): $\text{If } A=B(1+\tfrac r{100}) \text{ then } B \text{ is } \frac{r}{100+r}\times100\%\text{ less than } A;\ \text{if } A=B(1-\tfrac r{100}) \text{ then } B \text{ is } \frac{r}{100-r}\times100\%\text{ more than } A$
  - Shortcut: Write $r\% = \frac{a}{b}$: more by $\frac{a}{b}$ means less by $\frac{a}{a+b}$ (25% more ⇒ 20% less).
- [Reverse percentage (find the original)](/formulas/percentage#reverse-percentage): $\text{original}=\frac{\text{final}}{1\pm r/100}$
  - Shortcut: If the known value is $k\%$ of the whole, whole $= \text{value}\times\frac{100}{k}$ (unitary method: 1% first).
- [Successive change and constant growth](/formulas/percentage#successive-change): $\text{net }\%=a+b+\frac{ab}{100}\ (- \text{ for decreases});\ P_n=P_0\left(1+\frac r{100}\right)^n$
  - Shortcut: For three or more changes, multiply the multipliers: $1.12\times1.23\times0.66$, then subtract 1.
- [Buy x get y free](/formulas/percentage#free-items-discount): $\text{effective discount}=\frac{y}{x+y}\times100\%$
- [Income = expenditure + savings](/formulas/percentage#income-expenditure-savings): $I=E+S;\ \Delta S=\Delta I-\Delta E\ (\text{in absolute terms})$
  - Shortcut: % change in $S = \frac{I\,i - E\,e}{S}$, where $i, e$ are the % rises of income and expenditure (take $I = 100$).
- [Election vote equations](/formulas/percentage#election): $\text{valid}=\text{polled}\times(1-\text{invalid}\%);\ \text{margin}=(p_1-p_2)\%\times\text{valid}$
  - Shortcut: Chain the multipliers: margin $= V\times t\times(1-i)\times(p_1-p_2)$; divide the given margin by that product.
- [Price x consumption = expenditure](/formulas/percentage#price-consumption): $\text{To keep expenditure fixed after a } r\%\text{ price rise, cut consumption by } \frac{r}{100+r}\times100\%$
  - Shortcut: If price and consumption change by $p\%$ and $c\%$, expenditure changes by $p + c + \frac{pc}{100}$ %.
