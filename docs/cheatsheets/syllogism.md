# Syllogism: cheat sheet

- [Venn possible cases](/formulas/syllogism#venn-cases): $\text{Draw every Venn case allowed by the statements; a conclusion follows only if it holds in every case (a 'possibility' if it holds in at least one).}$
- [Either-or complementary pair](/formulas/syllogism#either-or): $\text{If two conclusions about the same two classes are each uncertain but exactly one must hold (Some/No or All/Some-not), answer 'either I or II follows'.}$
