# Classification: cheat sheet

- [Letter-cluster gap pattern](/formulas/classification#letter-gap-pattern): $\text{Write each cluster as alphabet positions, list the gaps between neighbours; the cluster whose gap pattern differs is the odd one.}$
  - Shortcut: Memorise EJOTY ($5,10,15,20,25$) and count gaps from the nearest anchor.
- [Number pair odd-one-out rule](/formulas/classification#number-pair-rule): $\text{Find one rule } y=f(x) \text{ (difference, ratio, } kx+c, x^2, x(x+1)\text{) that 3 pairs obey; the pair that breaks it is odd.}$
  - Shortcut: Two pairs give $k$ and $c$ of $y = kx + c$; plug in the other two and the misfit is the answer.
- [Number triad odd-one-out rule](/formulas/classification#number-triad-rule): $\text{Find } c=p\,(a\ \square\ b)+q \text{ with } \square\in\{+,\times,-\} \text{ that 3 triads obey; the triad that fails is odd.}$
  - Shortcut: Divide $c$ by $a+b$ and by $ab$: a whole-number constant across three triads is the rule.
- [Number property check](/formulas/classification#number-property): $\text{Test every number for one property (prime, perfect square/cube, divisible by } k\text{); the number without it is odd.}$
  - Shortcut: Digit sum divisible by 3 kills primality at once; check 7, 11 and 13 next.
- [Word category membership](/formulas/classification#word-category): $\text{Name the category or relation of each word (pair) - synonym, antonym, part-whole, item-count - and pick the one that differs.}$
