# Missing Number: cheat sheet

- [Same operation across sets](/formulas/missing-number#set-operation-rule): $\text{Find the rule } f \text{ with } f(\text{given}) = \text{result in every complete set; apply } f \text{ to the open set.}$
  - Shortcut: Compare results with products and sums first: $\frac{ab}{c}$ or $ab - c$ being a small whole number usually shows the rule.
